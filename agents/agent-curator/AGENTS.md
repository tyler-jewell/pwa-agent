# agent-curator

Scaffold only (no mesh binary in this pass). Creates and evaluates agents.

## Policy

- New agents start with **default-deny** peer mesh (no agent-to-agent tools by default).
- Each agent has one sole context file: `agents/<name>/AGENTS.md` (or config override).
- Skill grants are empty until skill-curator grants them (D6/D7).

## Law

Follow root **STANDARDS.md** / **CONTRIBUTING.md**. No `docs/` dumps.
